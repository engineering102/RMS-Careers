# Week 26 cheat sheet

## Demo Day (CAP-M4, 100 marks)

| Criterion | Marks |
|---|---|
| Functionality and completeness (live) | 25 |
| Architecture and data design | 15 |
| Code quality and Git practice | 15 |
| Testing and reliability | 10 |
| Security and deployment | 10 |
| Documentation | 10 |
| Presentation and viva | 15 |

SAP capstone: "process accuracy and configuration rationale" and "integration and document-flow evidence" replace the
code-quality and security rows.

**Morning of:** open the live app early · demo accounts logged in on separate profiles · backup video downloaded ·
charger, adapter, hotspot · notifications off.

**Demo breaks:** stay calm → one quick fix → switch to the recorded video → explain the cause afterwards.

**Viva:** trace your feature from click to database and back; be ready to change a rule live.

## Online assessment tactics

- Read the instructions screen: section timers, going back, negative marking.
- Two passes: under-a-minute questions first, then the marked ones.
- No negative marking → never leave blanks.
- Coding: read constraints (n ≤ 10⁵ → O(n log n) or better), brute force first if stuck, test edge cases.

## Aptitude formulas

| Topic | Formula |
|---|---|
| Successive % | multiply factors: +20%, −20% → 0.96 |
| Profit % | profit ÷ CP × 100 |
| Time and work | add daily rates: 1/a + 1/b |
| km/h → m/s | × 5/18 |
| Average speed (equal distances) | 2xy / (x + y) |
| SI / CI amount | PRT/100 · P(1 + R/100)ⁿ |
| nCr | n! / (r!(n − r)!) |

Reasoning: differences for series · A = 1…Z = 26 for coding · draw trees, directions and Venn diagrams.

## Interviews

- **Tell me about yourself:** present → past → future, 60–90 s.
- **STAR:** Situation · Task · **Action** · Result.
- **Project:** what → how → why → what if. "We" for the team, "I" for your work.
- **Coding:** clarify → examples → brute force → optimise → code aloud → test → complexity.
- **Ask them:** first months, code review culture, what success looks like.

## Profiles

GitHub: profile README, 6 pinned repos with READMEs and live links · LinkedIn: photo, headline, About, Featured, posts ·
Naukri: headline, key skills, latest résumé, alerts · Portfolio: live, project cards, résumé download.

**Never pay** a "registration" or "training" fee for a job. Verify on the official careers page.
